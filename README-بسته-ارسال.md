# بسته‌ی ارسال مقاله‌ی سوم — EENR (نسخه‌ی نهایی، ۲۶ شهریور ۱۴۰۵)

**عنوان:** اقتصاد سنجش خسارت انرژی جنگ: معیار، دامنه و افق — با چارچوبی برای تخصیص ارزبری در بازسازی
**نشریه‌ی هدف:** فصلنامه اقتصاد محیط‌زیست و منابع طبیعی (EENR)، دانشگاه علامه طباطبائی

**نسخه:** ۸٫۱ (نهایی ارسال) — نسخه‌ای که همه‌ی ارقام، ارجاع‌ها و آزمون‌های روشی آن با اسناد پشتیبان تطبیق داده شده است. بسته را طوری چیده‌ایم که خواننده بتواند مسیر هر عدد را تا سند اصلی دنبال کند؛ ازاین‌رو نگاشت «عدد ← سند ← نشانی» در بخش ۳ آمده است.
